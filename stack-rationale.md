# Three Roads: Choose Your Stack with AI

## My Constraints
- Free tools only.
- Beginner to intermediate skill level in HTML, CSS, JavaScript, Python, and basic Machine Learning.
- My portfolio should display my projects, GitHub repositories, internship work, certificates, and resume.
- My work should be easy to maintain and accessible online. I do not need a backend yet.

## Three Stack Options

### Option 1: HTML + CSS + JavaScript
- Hosting: GitHub Pages
- Backend: No
- Trade-off: Very simple and free but limited for larger projects.

### Option 2: React + Vite (Chosen)
- Hosting: Vercel
- Backend: No
- Trade-off: Modern, scalable, easy to maintain, and suitable for my portfolio.

### Option 3: Next.js + Firebase
- Hosting: Vercel + Firebase
- Backend: Yes
- Trade-off: Powerful but more complex and unnecessary for my current needs.

## My Decision

I chose React with Vite hosted on Vercel.

It is free, modern, and easier to maintain than a plain HTML website while being much simpler than a full-stack application. It lets me showcase my projects, GitHub repositories, internship work, certificates, and resume professionally.

I did not choose HTML/CSS/JavaScript because it becomes difficult to maintain as the portfolio grows. I also did not choose Next.js with Firebase because I do not need a backend yet, and it would add unnecessary complexity.

React with Vite is the best balance for my current skill level. I can finish it within two weeks, maintain it easily, and it displays my work professionally.
